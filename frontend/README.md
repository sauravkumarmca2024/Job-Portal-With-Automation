# Frontend Template

This is the runnable React + Vite foundation for **Job Portal With Automation**.
It contains configuration files, common dependencies, a simple starter screen,
and empty feature folders for team development.

## Run locally

```bash
npm install
npm run dev
```

## Validate before a pull request

```bash
npm run build
npm run lint
```

## Team folders

- `src/assets`
- `src/components`
- `src/pages`
- `src/routes`
- `src/services`
- `src/store`

Feature code should be added through separate branches and pull requests.
